Stack-Up

Results update live as you edit
Ref. ASME Y14.5 · RSS & Monte Carlo per standard tolerance-analysis practice

A tolerance stack-up sums the variation of every feature in a dimension chain to predict whether an assembled result — a gap, a fit, an alignment — holds within spec. Build the chain below and check it three ways: worst case, RSS, and a 10,000-sample Monte Carlo.

How to use it

1

Set the requirement

Name the gap, fit, or alignment you're checking and enter its lower and upper spec limits (target is optional).

2

Build the chain

Click "Add contributor" for every feature in the path — each part dimension that affects the result. Or hit "Load example" to see one filled in.

3

Set direction & tolerance

Toggle + / − to set which way each contributor pushes the stack, enter its nominal and ± tolerance, and pick Normal or Uniform distribution.

4

Read the verdict

The results panel updates live — check the pass/fail call, the spec-fit gauge, and how Worst Case, RSS, and Monte Carlo compare.

5

Tighten it up

If it fails, open "Top contributors" to see which feature drives the most variation, and "Show the math" to see exactly how each number was derived.

Worst case

Sums every tolerance at its extreme. Conservative — use it for safety-critical or non-adjustable features.

RSS

Treats contributors as independent normal distributions and reports nominal ± √(Σ tol²). Realistic for controlled processes.

Monte Carlo

Simulates 10,000 assemblies from each contributor's assigned distribution and reports actual yield against spec.
